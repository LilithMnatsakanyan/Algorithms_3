### **🛠️ How to Use the Repository**

1.  **Clone the repository** to your local machine:

    ```bash
    git https://github.com/LilithMnatsakanyan/Algorithms_3
    cd Algorithms_3
    ```

2.  **Run the script** for the specific algorithm you want to test (e.g., `dijkstra.py` or `bfs_alg.py`):

    ```bash
    python dijkstra.py
    ```

Each algorithm is implemented in **Python**. Feel free to modify the input data to test them with different datasets and explore the performance of each algorithm with varying input sizes. It’s a great way to experiment and deepen your understanding of algorithmic concepts!
